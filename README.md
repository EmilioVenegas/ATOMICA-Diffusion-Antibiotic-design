# ATOMICA-Diffusion-RL: De Novo Antibiotic Design

## 🚀 Project Overview

Despite advances in antibiotic discovery, rapid bacterial resistance remains a critical global issue. Traditional computational methods often struggle with data scarcity and fail to generalize to new chemical spaces. 

**ATOMICA-Diffusion-RL (AtomDiffRL)** is a unified, multi-stage pipeline for *de novo* antibiotic design. It integrates a geometric diffusion model (DiffSBDD) with an evolutionary reinforcement learning (RL) loop, conditioned on atom-scale protein embeddings generated by ATOMICA. By conditioning the generative model on the rich, learned interaction embeddings of a protein pocket rather than just raw atomic coordinates, the pipeline generates chemically valid molecules with highly favorable physicochemical and druggability features. 

This strategy is target-agnostic but is particularly focused on optimizing leads against pathogens like multidrug-resistant *Acinetobacter baumannii*, *Pseudomonas aeruginosa*, and *Klebsiella pneumoniae* (specifically targeting the PBP3 division pathway).

## 🧠 Core Architecture & Innovation

The primary innovation of this framework is creating an "adapter" methodology that conditions geometric diffusion on a foundation model's learned interaction field.

### 1. ATOMICA Embedding Generation
The pipeline converts protein pockets into a format suitable for ATOMICA:
* **Graph Extraction:** Atoms are converted into nodes (filtered by predefined vocabularies) alongside a "virtual" global node. Edges are dynamically constructed via K-Nearest Neighbors (KNN).
* **Atom-Level Embeddings:** Generated using an SE(3)-Equivariant GNN (e3nn Tensor Product Convolution Layers). These embeddings capture fine-grained local chemical environments and geometric structures.

### 2. SE(3) Cross-Attention Conditioning Mechanism
We modified the EGNNDynamics module in DiffSBDD to accept ATOMICA embeddings via a **Cross-Graph Convolutional Layer (CrossGCL)**.
* **Keys and Values (H_P):** The static ATOMICA atom-level pocket embeddings.
* **Queries (H_L):** The intermediate ligand features from the diffusion model.
* This SE(3)-equivariant cross-attention allows the generating ligand atoms to dynamically "attend" to relevant parts of the pocket based on learned chemical compatibility. Strict masking is utilized to handle variable-sized protein pockets without padding artifacts.

## 🧬 Evolutionary Reinforcement Learning (RL) Loop

To optimize for therapeutic properties, AtomDiffRL employs a lightweight evolutionary RL loop focusing on ADMET (Absorption, Distribution, Metabolism, Elimination, Toxicity).

1.  **Generation & Filtering:** Sample 500 molecules per iteration. Chemically implausible structures are strictly eliminated using REOS (Rapid Elimination of Swill) filters.
2.  **Scoring:** Molecules are scored using ADMET-AI (a state-of-the-art model outputting a composite score of 8 physicochemical and 41 ADMET properties). 
3.  **Evolution:** For a given target (e.g., P. aeruginosa PBP3), the top 5 molecules with the highest composite ADMET scores are selected. 
4.  **Iteration:** These top candidates are passed forward to generate 100 new molecules each, forming a new ensemble of 500. This process is repeated for three total iterations to heavily bias the output toward biophysically plausible, high-potency molecules.

## 📊 Evaluation Pipeline

To benchmark candidates without wet-lab assays, we developed an *in silico* evaluation pipeline (validated initially on CDK2):
* **Boltz-2 Integration:** Generates a binder probability (hit-likelihood), an affinity score (pIC50 equivalent), and a complex confidence score (pLDDT, indicating structural reliability).
* **AutoDock Vina:** Provides classic docking scores and interaction profiling.
* **Molecular Descriptors:** Evaluates Tanimoto similarity against DrugBank references and checks synthetic accessibility.

## 💾 Data Preparation & Preprocessing

Models were trained utilizing a curated subset of the **CrossDocked Dataset**. The initial 164,000 complexes were heavily filtered for druggability (15-80 atoms), clashes, binding proximity (<6Å), and favorable AutoDock Vina scores, resulting in ~40,000 high-quality complexes. 

We provide a script to process this dataset and generate the necessary ATOMICA embeddings:

```bash
python process_expert_atomica.py
```
This script loads the pre-trained ATOMICA model, filters the dataset, computes pocket embeddings, and saves the formatted `.pt` files.

## 💻 Usage & Scripts

### Training the Conditioned Model
To train the SE(3) cross-attention model with ATOMICA conditioning:

```bash
python DiffSBDD/train.py --config DiffSBDD/configs/crossdock_fullatom_cond.yml
```
*Key parameters: `atomica_nf` (Embedding dimension, default: 32), `cross_attn_type` ('full').*

### Generation & Optimization

**1. Standard Ligand Generation (`generate_ligands.py`)**
Generates *de novo* ligands using the ATOMICA embeddings of your target PDB.

```bash
python DiffSBDD/generate_ligands.py \
    checkpoints/crossdocked_fullatom_cond.ckpt \
    --pdbfile example/5ndu.pdb \
    --ref_ligand example/5ndu_linked_mols.sdf \
    --atomica_config ATOMICA/pretrain/pretrain_model_config.json \
    --atomica_weights ATOMICA/pretrain/pretrain_model_weights.pt \
    --outfile generated_ligands.sdf
```

**2. RL-Guided Optimization (`optimize.py`)**
Optimizes ligands for a specific pocket, guiding generation with the ADMET/RL pipeline.

```bash
python DiffSBDD/optimize.py \
    --checkpoint checkpoints/crossdocked_fullatom_cond.ckpt \
    --pdbfile example/5ndu.pdb \
    --ref_ligand example/5ndu_linked_mols.sdf \
    --atomica_config ATOMICA/pretrain/pretrain_model_config.json \
    --atomica_weights ATOMICA/pretrain/pretrain_model_weights.pt \
    --outfile output.sdf
```
